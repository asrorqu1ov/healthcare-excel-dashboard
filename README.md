# 🏥 Healthcare Admissions & Billing Dashboard (Excel)

---

## English

This project presents an **interactive Excel dashboard** designed to analyze hospital patient admissions, weekday patterns, and billing performance using pivot tables, slicers, timelines, and KPIs.

---

### 📊 Dashboard Overview

![Dashboard Overview](images/dashboard_overview.png)

The dashboard provides a high-level overview of:
- Total number of patients
- Billing summary
- Admission patterns by weekday and admission type
- Distribution of patients by medical condition and gender

---

### 🎯 Project Objectives

- Analyze hospital admissions data in a clear and structured format  
- Identify the busiest weekdays for patient admissions  
- Understand patient distribution by admission type and medical condition  
- Build a clean, management-friendly Excel dashboard  

---

### 🧮 Key KPIs

- **Total Patients**
- **Total Billing Amount**
- **Average Billing per Patient**
- **Emergency Admissions Count**
- **Busiest Admission Day**

All KPIs dynamically update based on slicer and timeline selections.

---

### 📈 Visualizations Included

- Patients by Medical Condition (Bar Chart)
- Patient Distribution by Gender (Donut Chart)
- Admissions by Type (Column Chart)
- Admissions by Weekday (Column Chart)
- Billing Amount by Insurance Provider (Bar Chart)

---

### 🎛️ Interactivity

The dashboard includes:
- **Slicers** for:
  - Gender
  - Medical Condition
  - Admission Type
  - Insurance Provider
- **Timeline** for Date of Admission

These tools allow users to filter and explore the data interactively.

---

### 🗂️ Dataset

- Source: `healthcare_dataset.csv`
- Contains patient demographics, admission details, medical conditions, and billing information

---

### 🛠️ Tools Used

- Microsoft Excel  
  - Pivot Tables & Pivot Charts  
  - Slicers and Timeline  
  - Formulas for KPI calculations  
  - Shapes for KPI cards  

---

### 📌 Key Insights

- Emergency admissions account for a significant portion of total patients  
- Certain weekdays consistently show higher admission volumes  
- Billing amounts vary considerably across insurance providers
